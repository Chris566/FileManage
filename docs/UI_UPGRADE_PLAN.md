# FileManage 界面升级计划 v2

> 状态：已评审（菜单形态=顶部菜单栏；帮助=内置窗口；文档=本文档）
> 基线版本：v1.4.1（commit afdbbb0）
> 关联文档：[DESIGN.md](DESIGN.md)

## 一、目标与范围

在不改变三层架构（Core 纯逻辑 / Infrastructure IO / WPF UI）与现有交互习惯的前提下，通过菜单栏系统、"关于"/"帮助"窗口、版本信息展示与快捷键/记忆增强，提升用户体验与功能完整性。全部新 UI 文本接入语言字典（zh-CN / en-US），延续 DynamicResource 即时切换；全部配色沿用 Light/Dark 主题字典。

## 二、总体设计

### 2.1 界面布局（自上而下）

```
FileManage  PowerBy 吴东东（Chris）                    ← 头部（移除原 主题/语言 下拉框）
──────────────────────────────────────────────
外观(O)   语言(L)   工具(T)   帮助(H)   关于(A)        ← 新增顶部菜单栏
──────────────────────────────────────────────
[刷新预览] [执行] [撤销上次] [历史…] [重复检测…]        ← 现有工具栏保持不变
──────────────────────────────────────────────
左列参数区（源目录/重命名/分类整理/执行选项） | 右列预览区
──────────────────────────────────────────────
进度条 | 状态文本                          v1.5.0    ← 状态栏右下角新增版本标签
```

常用操作保留工具栏大按钮；菜单提供完整入口、快捷键展示与迁移后的设置项。

### 2.2 菜单结构

| 菜单 | 子项 | 快捷键 | 说明 |
|---|---|---|---|
| 外观(O) | ○ 浅色 / ○ 深色（单选标记） | — | 迁移自头部下拉，沿用 `UIStateService.ApplyTheme`，IsChecked 双向绑定 |
| 语言(L) | ○ 中文 / ○ English（单选标记） | — | 迁移自头部下拉，沿用 `UIStateService.ApplyLanguage` |
| 工具(T) | 规则管理… / 重复检测… / 历史记录… | Ctrl+R / Ctrl+D / Ctrl+H | 复用 MainViewModel 现有 RelayCommand |
| 帮助(H) | 用户指南 / 常见问题 / 项目主页 | F1 打开帮助窗口 | HelpWindow 内置选项卡；项目主页跳转 GitHub |
| 关于(A) | 关于 FileManage… | — | AboutWindow 模态窗口 |

### 2.3 交互细节

- **响应式**：菜单为紧凑顶栏，最小窗口宽度 860 下不换行、不溢出；子菜单 `MaxDropDownHeight` 限高滚动。
- **展开/折叠动画**：子菜单弹出 150ms 淡入 + 轻微下滑（`PopupAnimation=Fade` + 自定义 MenuItem 控件模板中的 TranslateTransform/ScaleTransform）；动画时长集中定义为资源，尊重系统"减少动画"偏好时降级为直接显示。
- **快捷键**：通过 Window 级 `InputBindings` 注册，菜单项以 `InputGestureText` 展示；`F5` 刷新预览、`Ctrl+E` 执行、`Ctrl+Z` 撤销上次、`F1` 帮助。
- **菜单记忆**：`AppSettings` 新增可选字段（左列各分组折叠状态、窗口尺寸与位置），旧 `settings.json` 无字段时取默认值，向后兼容；由 `UIStateService` 统一保存。

## 三、版本信息统一（关键前置）

现状问题：`FileManage.App.csproj` 的 `Version=1.0.0` 与发布 tag（当前 v1.4.1）不一致，直接读程序集会显示错误版本。

方案：

1. CI 发布注入版本：publish job 改为 `dotnet publish -p:InformationalVersion=<tag 去掉 v> -p:BuildDate=<UTC 日期>`；本地调试构建回退显示 `dev`。
2. 状态栏右下角新增版本标签，文本 `v{InformationalVersion}`；与"关于"窗口读取同一来源（程序集 InformationalVersion），天然一致。
3. 悬停 tooltip 显示完整信息：`v1.5.0 · 构建 2026-09-01 09:57 (UTC)`。
4. 单击版本标签 → 打开"关于"窗口。

## 四、"关于"窗口（AboutWindow，模态）

- 版本号与构建日期（与右下角同源）
- 版权信息：`Copyright © 2026 吴东东（Chris）`
- 许可协议摘要 + 项目 LICENSE 链接
- 开发者信息与联系方式（GitHub 主页 / Issues）
- "更新日志"按钮 → 内嵌查看器渲染 `CHANGELOG.md`（随版本维护），并提供 GitHub Releases 跳转

## 五、帮助窗口（HelpWindow，模态）

- 两个选项卡：用户指南 / 常见问题；内容为本地化静态页面（随语言字典切换），离线可用
- 提供"项目主页""问题反馈"外链按钮
- `F1` 全局唤起

## 六、本地化与主题

- 新增资源键：`S.Menu.*`（菜单标题/子项）、`S.About.*`、`S.Help.*`、`S.Tip.Version`、`S.Status.*` 等，zh-CN 与 en-US 同步补充
- `Controls.xaml` 新增 Menu/MenuItem 完整控件模板（含悬停/按下/勾选/禁用态与弹出动画），画刷全部 DynamicResource 引用，避免深色模式白底残留（参照此前 DataGrid 教训，M1 优先验证深色主题）

## 八、实施与测试要求

- **兼容性**：不改动 Core/Infrastructure 公共接口；`AppSettings` 仅追加可选字段；旧设置文件无损加载。
- **测试矩阵**：浅/深主题 × 中/英语言 × 100%/125%/150% DPI × 1024/1920 宽度。
- **回归**：现有 115 项测试全部通过；新增 VM 单元测试（菜单命令路由、设置序列化兼容、版本号读取）。
- **文档**：README 功能说明、用户指南内容、CHANGELOG.md 更新。

## 九、验收标准

1. 五个菜单功能正常工作、无交互错误；主题/语言迁移后行为与原下拉完全一致（即时切换 + 持久化）。
2. 菜单展开、关于/帮助窗口打开响应时间 ≤ 300ms。
3. 测试矩阵各组合下无错位、无白底残留、无文本截断。
4. 右下角版本号、tag、关于窗口三者版本一致；悬停提示完整、点击打开关于窗口。
5. 用户能通过菜单、工具栏、快捷键三种途径触达全部新增功能。

## 十、风险与对策

| 风险 | 对策 |
|---|---|
| 深色模式 Menu 白底残留 | M1 优先在深色主题下验收 Menu/MenuItem 全套模板 |
| CI 版本注入影响发布流水线 | M2 单独提交并先以测试 tag 演练，确认 Release 产物版本正确后再合并 |
| 迁移下拉框后老用户不适应 | 工具栏常用按钮保留；菜单项带单选标记，状态一目了然 |
| 设置文件向后兼容 | 新字段全部可选 + 默认值，单元测试覆盖旧 JSON 反序列化 |
